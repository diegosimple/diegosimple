### 🚀 Sobre mim

- 🏢 **CEO Freelance**
- 🧾 Especialista no **domínio fiscal brasileiro**: NF-e, NFC-e, CT-e, MDF-e, NFS-e, SPED EFD, PGDAS-D
- 📐 Acompanhando de perto a **Reforma Tributária** (IBS / CBS / IS) nos sistemas
- ⚡ Filosofia: código simples, direto e **rápido** — desempenho em primeiro lugar
- 🔧 Trabalhando agora: **ERP web Zeus PRO** (Laravel) e o **Erp2Id** (Delphi)

### 🛠️ Produtos que desenvolvo

| Produto | O que é | Stack |

| **Zeus PRO / ZeusFOOD** | ERP + PDV para varejo e food service | Delphi · Firebird · ACBr |
